IPL Data Analysis Project 🏏📊

Overview

This project focuses on performing in-depth data analysis on Indian Premier League (IPL) match data using Python. It extracts valuable insights from historical match records, player performances, team statistics, and venue-based outcomes. By visualizing data through graphs like bar charts, scatter plots, line graphs, heatmaps, and histograms, this project helps uncover key trends and patterns in the IPL.

Dataset

The analysis is based on two datasets downloaded from Kaggle:

matches.csv: Contains match-level details including teams, venues, winners, and match results.

deliveries.csv: Contains ball-by-ball data, including runs scored, wickets, and player information.

Tools & Libraries

Python

Pandas for data manipulation and analysis

Matplotlib and Seaborn for data visualization

Jupyter Notebook for interactive analysis

Features & Analysis

1. Match Outcome Analysis

Visualized match outcomes (Win/Loss) across different IPL seasons.

Analyzed team performance based on historical data and seasonal trends.

2. Player Performance Analysis

Tracked individual player statistics like total runs, wickets, and strike rates.

Used bar graphs and scatter plots to visualize player contributions.

3. Team Comparison

Compared team performance using line charts and pie charts for win percentages.

Analyzed the impact of team changes, including player transfers and injuries.

4. Venue Performance

Evaluated match outcomes across different IPL venues.

Presented venue-based performance using heatmaps and bar charts.

5. Run Rate & Scoring Analysis

Visualized average run rates for teams and players.

Tracked scoring trends over the years using line graphs.

6. Best Batting Partnerships

Identified and visualized top batting partnerships using histograms.

Analyzed successful partnerships based on total runs and boundary rates.

How to Run

Clone this repository.

Install the required libraries using:

pip install pandas matplotlib seaborn

Open the Jupyter Notebook and run the cells in sequence.
